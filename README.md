# Installer v2

A small Bash-only interactive terminal installer interface.

## Try it

    bash install.sh

Use **Up / Down** to navigate, **Enter** to select and **Esc** to go back. Press **1–3** for a quick selection. No extra packages are required. When no interactive terminal is available, the menu accepts numeric input.

**Current scope:** menu and presentation only. The installer does **not** install Docker, PHP-FPM, PostgreSQL, Redis, Nginx or anything else yet. All selections are previews, and no host configuration is changed.
